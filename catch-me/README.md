# Catch Me
Online multiplayer chase game set in Mumbai (PWA: works on iOS + Android browsers, installable to home screen).

## Run
    npm install
    npm start        # http://localhost:3000

Phones on the same Wi-Fi: open http://<your-PC-LAN-IP>:3000
Play with friends anywhere: deploy this folder to Render / Railway / Fly.io (Node, start command `npm start`).
Use the https URL it gives you, then "Add to Home Screen" (iPhone) or "Install app" (Android).
